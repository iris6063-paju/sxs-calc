# 소드 x 스태프 전투 계산기 (비공식)

직업 · 공격 · 방어 · 생명 · 속도 · 전투스킬을 입력하면 몬테카를로 시뮬레이션으로 **승리 확률**을 계산하는 팬 제작 도구입니다.
1:1, 다대일, 다대다(팀 구성), 몹 지정을 지원하고, 대표 전투 한 판을 3D 디오라마에서 재생합니다.

- **전투 스킬 4칸** (칸 순서 = 사용 순서, ▲▼로 순번 변경) · **비법 4칸** · **판타몬**(지원 스킬 + 성년 실체화, 공격·방어·생명·속도 입력)
- **전투 불러오기**: 환상계단 585층, 일일 던전 28종(방별), 길드 토벌(길드 보스) 1~460층 전체, 신수 시련 84단계 — 길드 토벌·신수 시련은 층·단계별 보스 능력치를 게임 공식(클라이언트 계산식)으로 미리 계산해 담았습니다
- **배틀 화면**: 행동 단위 타임라인(대미지 막대 · 쓰러짐 표시, 끌어서 이동), ◀/▶▶ 한 행동씩 보기, 끝으로, 진행 설명 한 줄, 전장 효과 칩(균형의 미 · 라운드 제한 · United We Stand 등), 3D 유닛 머리 위 상태 칩, 유닛 상태 패널(생명 · 실드 · 상태 · 중첩 · 남은 턴), 줄을 누르면 그 장면부터 다시 보는 전투 로그, 결과 비율대로 고른 다시 볼 전투 10판, 미니맵에서 끌어 정하는 시작 위치, 위에서 보기 시점, 전장 바닥 6종
- **몹 스킬 아이콘**: 몹 카드의 스킬 · 비전 목록에 게임 아이콘(`assets/mobskills/`, 39종)을 표시합니다
- **몹 비전(패시브)**: 몹 · 보스 비전 71종 중 51종을 전투에 반영합니다(원소체 · 면역, 반격, 누적 대미지 광역기, 격노, 중첩형 대미지 감소, 자폭 등). 수치가 공개되지 않은 18종은 추정값이며 「몹 비전 추정값 반영」으로 끌 수 있고, 소환 · 형태 전환 등 20종은 몹 카드에 ⚠로 표시합니다
- **카툰 렌더링 3D**: 전투 장면의 캐릭터 · 몹 · 보스는 GPT 6.1 sol이 설계한 3D 모델(`assets/toon/*.json`, 프리미티브 부품 목록)을 `js/toon.js`가 툰 셰이딩(3단 명암) · 잉크 외곽선 · 애니메 눈(표정 변화)으로 그립니다. 영웅 6종은 SD 시트 그림을 참고 이미지로 넣어 설계했고, 관절(다리 · 팔 · 손 · 머리 · 망토)이 대기 · 이동 · 공격(검 휘두르기 / 쌍검 / 지팡이 · 마도서 내밀기) · 스킬(회전 베기 · 방패 강타 · 두 손 영창) · 피격 · 쓰러짐 동작을 합니다. 몹은 그림 종류 42가지 모델을 몹마다 재채색해 쓰고, 신수 6종(폭풍 그리핀 · 불사조 · 야마타노 오로치 · 태고의 용 · 은하 메카 · 욜드라)은 전용 보스 모델입니다(날개 · 목 · 꼬리 관절이 움직임). 섬 · 나무 · 바위도 같은 툰 셰이딩과 외곽선으로 맞췄습니다
- **캐릭터 SD 그림**: 18직업은 사용자가 제공한 SD 에셋 개발 시트 6종(전사 · 마법사 · 기사 · 투사 · 주술사 · 현자, 전직 계열은 같은 그림)에서 잘라낸 스프라이트(`assets/sheets`)로 그립니다. 전투에서는 대기 8 · 이동 6 · 공격 6 · 스킬 8 · 피격 6프레임이 행동에 맞춰 재생되고(단일 대상 = 공격, 범위 · 지원 = 스킬, 맞으면 피격, 이동 · 도약 중 이동), 직업별 이펙트(검격 · 쌍검 아크 · 방패 돌진 · 마법 화살 · 마법진 · 치유의 빛 · 피니시 등)가 단일 공격 · 투사체 · 범위 · 지원 · 처치에 맞춰 나옵니다. 유닛 상태 패널에는 표정 아이콘(기본 · 신남 · 놀람 · 당황 · 화남 · 졸림 등)이 전투 상황에 따라 바뀌고, 캐릭터 카드에는 대기 애니메이션과 방향 시트(정면 · 3/4 · 측면 · 후면)가 나옵니다. 승급 직업(3차 이상)은 오라가 더해집니다
- **몹 그림**: 몹 42종은 GPT 6.1 sol이 그린 SVG(`assets/gpt`)를 재채색해 애니메이션합니다(시트를 불러오지 못하면 영웅도 이 SVG 리그로 대체)
- **공식 명칭 · 아이콘**: 전투 스킬 118종 · 비법 114종의 한국판 이름 · 설명 · 아이콘(`assets/skills/skill_<ID>.webp`)과 직업명, 능력치 · 상태 이상 용어를 한국판 게임 리소스 기준으로 표기합니다(소드X스태프허브 스킬 도감 대조)

> 게임 개발사·퍼블리셔와 무관한 비공식 도구입니다. 결과는 커뮤니티가 정리한 공식에 기반한 추정치입니다.

## 실행

빌드 과정이 없는 정적 사이트입니다. ES 모듈과 Web Worker를 쓰므로 `file://`로 직접 열지 말고 로컬 서버로 여세요.

```bash
node serve.mjs
```

브라우저에서 `http://localhost:5173` 을 엽니다. (포트 변경: `PORT=8080 node serve.mjs`)

엔진 점검:

```bash
node tools/test_engine.mjs
node tools/test_extra.mjs
node tools/test_passives.mjs
node tools/test_pets.mjs
```

## 배포

폴더 전체를 그대로 올리면 됩니다. 모든 경로가 상대 경로라 하위 경로(`https://example.com/sxs/`)에서도 동작합니다.

| 호스팅 | 방법 |
| --- | --- |
| GitHub Pages | 저장소에 푸시 → Settings › Pages › Branch 지정 (루트) |
| Netlify / Cloudflare Pages / Vercel | 빌드 명령 없음, 출력 디렉터리 = 저장소 루트 |
| 일반 웹서버 | 폴더 복사. `.js`가 `text/javascript`, `.webmanifest`가 `application/manifest+json`으로 나가면 충분 |

외부 요청은 글꼴 2종(Pretendard, JetBrains Mono)뿐이며, 막혀 있어도 시스템 글꼴로 동작합니다. three.js는 `vendor/`에 포함되어 있습니다.
`tools/` 폴더는 개발용이므로 배포에서 빼도 됩니다.

## 계산 방식 요약

- **행동 순서**: 행동 간격 = 100000 ÷ √속도. 한 턴에 최대 4칸 이동 후 준비된 전투스킬을 슬롯 순서대로 모두 시전.
- **대미지**: (공격력×계수+고정값) × 공격력/(공격력+방어력) × 원소 배율 × (1+대미지 보너스)/(1+대미지 저항) × 막기·치명타 × 레벨 보정.
- **판정**: 실명 → 회피 → 막기 → 치명타. 막기 시 ÷max(1.5, 1+막기 대미지 저항−명중), 치명타 시 ×max(1.3, 1+치명타 대미지−치명타 저항).
- **PvP 전장 보정**: 캐릭터 대상 대미지 ×0.2, 12라운드부터 라운드마다 +10%p, 치유·실드 감소, 제어 효과 확률 1/3.
- **격자**: 21×20 보드, 5칸 폭 진형 자동 배치, 「많이 맞히는 위치 → 짧은 이동 → 낮은 체력 비율」 순으로 대상 선택.
- **몹 크기**: 보스는 2×2(4칸), 신수 시련의 신수는 3×3(9칸)을 차지합니다. 거리 · 사거리 · 범위 판정은 차지한 칸 중 가장 가까운 칸 기준입니다.
- **다단 히트**: 설명에 「대형 대상은 여러 번 맞을 수 있음」이 있는 스킬은 범위 안에 든 대상의 칸마다 1회씩 맞힙니다(예: 2×2 보스가 범위에 다 들어오면 4회). 「같은 대상에게 맞을 때마다 대미지 X% 감소」는 두 번째 타격부터 곱해서 적용하고, 튕김 · 연쇄 공격도 대형 대상을 칸 수만큼 다시 맞힐 수 있습니다. 「대형 대상 우선」 스킬은 대형 대상이 든 위치를 먼저 고릅니다.
- **스킬 이동**: 직선 돌진(대상 방향으로 N칸, 빈 칸까지 · 3×3 대상은 통과 못 함), 순간이동(대상 옆 빈 칸), 시전 후 후퇴, 넉백(확률 판정 · 옆으로 밀기 포함)을 계산과 3D 재생에 반영합니다. 스킬 이동은 턴 이동력(4칸)을 쓰지 않고, 도착 칸이 막혀 있으면 가장 가까운 빈 칸에 섭니다. 2×2 이상 대형 대상 · 빙결 · 속박 상태는 넉백 · 끌어당김을 받지 않습니다.

### 추정·미반영

- 몹 스킬 계수·쿨다운은 공개 자료가 없어 턴당 1스킬 · 계수 100%로 가정(화면에서 조정 가능). 격노 · 각성 등 특정 상태 전용 보스 스킬도 일반 순환에 넣었고, 자기 강화 · 소환 · 반격 자세 스킬은 빠져 있습니다. 혼돈 원소는 상성 없음으로 처리합니다.
- 몹 비전: 격노(속도 · 대미지 +20%), 중첩형 대미지 감소(중첩당 1%), 껍질 파괴(받는 대미지 +50%), 턴 시작 회복(최대 생명 3%) 등 18종은 게임이 수치를 공개하지 않아 추정값입니다. 비전이 주는 대미지는 몹 스킬과 같은 계수를 씁니다. 비전 이름은 공식 한국어를 찾지 못해 번역 표기입니다.
- 침식 등 지속 대미지는 턴당 공격력 25%로 추정.
- 몹 크기(보스 2×2, 신수 3×3)와 「대형 대상은 넉백되지 않음」은 공개 자료가 없어 게임 화면 · 설명(체형이 4칸보다 큰 적은 관통 불가)으로 추정한 값입니다.
- 소환수 · 분신 · 설치물 · 화상 지대 · 넉백 충돌 대미지 · 공포 · 열상, 등급(랭크) 보정은 반영하지 않습니다.
- 비법은 114종 중 77종을 반영하고 나머지는 ⚠로 표시합니다. 레벨 비례 고정 수치는 근사값입니다.
- 판타몬 19종의 지원 스킬 · 실체화 스킬 · 비전을 `tools/pets_fx.mjs` 표에서 원문과 대조해 반영합니다. 디버프는 수치 · 확률 · 지속 턴 · 중첩(나이트군 방어력 10% ×최대 3중첩)까지 반영하고, 실드 · 버프 · 행동 지연 · 처형 대미지 · 처치 폭발 · 연쇄 치유 · 튕김 · 대형 대상 추가 대미지 · 3턴 소멸(헥시티)도 반영합니다. 파바(양배추 강아지) · 순수(프리즈모라)는 추정값이고, 에어본 · 응징 · 혈원 · 수호천사 지속 효과는 공개된 효과가 없어 미반영(⚠ 표시)입니다. 멧돼지 「산악 돌진」의 넉백은 반영합니다. 판타몬 스킬의 한국어 이름 · 설명은 공식 자료를 찾지 못해 번역 표기입니다.
- 길드 토벌 · 신수 시련은 대미지 경쟁이므로 승률 대신 「아군 평균 총 대미지」를 보세요. 길드 토벌 보스의 United We Stand(처음 3턴 받는 대미지 −99%)는 반영하고, 층별로 고르는 강화 효과는 미반영입니다.
- 한국어 명칭: 전투 스킬 · 비법 · 직업은 한국판 리소스(소드X스태프허브), 환상계단 · 이그드라실 · 기신산 · 신수 시련 · 신수 6종 · 판타몬 7종은 한섭 이용자 위키 기준입니다. 나머지 몹 · 판타몬 · 몹 스킬 이름과 품질 이름(희귀~불멸)은 공식 한국어를 찾지 못해 임시 번역 또는 영문입니다.
- 스킬 · 직업 이름은 한국판 명칭(소드X스태프허브 대조)을 쓰고, 대조되지 않은 항목과 몹 이름은 비공식 번역입니다.

## 데이터 갱신

`tools/build_data.mjs` 는 내려받아 둔 위키 페이지(스킬 표, 스탯 기준표, 적 데이터 JSON)를 읽어 `js/gamedata.js`를 다시 만듭니다.
패치 후 수치가 바뀌면 같은 페이지를 다시 받아 실행하세요. 한글 이름과 스킬별 모델링 예외는 스크립트 안의 `OV`, `KO_MOB` 표에서 고칩니다.

```bash
node tools/build_data.mjs <내려받은_폴더> js/gamedata.js
```

스크립트가 읽는 파일 이름(모두 `https://www.purrwikimania.com` 기준, 원본 페이지는 저장소에 포함하지 않습니다):

| 저장할 파일명 | 경로 |
| --- | --- |
| `skills.html` | `/combat/skills` |
| `base-stats.html` | `/base-stats` |
| `stat-conversion.html` | `/stat-conversion` |
| `curves.json` | `/assets/curves.json` |
| `enemies_index.json` | `/assets/enemies/_index.json` |
| `enemy_skills.json` | `/assets/enemies/skills.json` |
| `fantasia_fa1.json` ~ `fantasia_fa4.json` | `/assets/enemies/fantasia_fa1.json` … |
| `curve_0.json`, `curve_1.json`, `curve_2.json`, `curve_st.json` | `/assets/enemies/curve_0.json` … |

`tools/build_extra.mjs <위키_폴더> <추가_폴더> js/gamedata2.js` 는 위 폴더에 더해 `conquest_gc.json`, `crucible_cr*.json`, `dungeons_dd*.json`, `curve_3.json`(모두 `/assets/enemies/`)과,
추가 폴더의 `pets.html`(`/pets`), `metahub_database.html`(`https://metahub.wiki/swordxstaff/ko/database/`, 한국판 스킬 · 비법 이름 · 설명 · 아이콘 주소), `metahub_builder.html`(`…/ko/builder/`, 보조 대조용)을 읽습니다.

아이콘은 `https://api.iconify.design/game-icons.json?icons=이름,이름,…` 응답을 저장해 `node tools/build_icons.mjs <json> js/icons.js` 로 만듭니다.
