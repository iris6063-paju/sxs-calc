# 전투 스킬 · 비법 아이콘

한국판 게임 리소스의 공식 아이콘입니다(소드X스태프허브 스킬 도감 대조, 2026-11-15). 권리는 게임 권리자에게 있습니다.

- 파일 이름: `skill_<스킬ID>.webp` — 전투 스킬 118종(예: `skill_10010.webp` 스턴 블로우), 비법 114종(예: `skill_10500.webp` 예지)
- ID는 `js/gamedata.js`(SKILLS) · `js/gamedata2.js`(CHARMS)의 `id` 값입니다.
- `icons.json`의 `ext`가 확장자를 정합니다. 비우면 속성 색 타일로 표시됩니다.
