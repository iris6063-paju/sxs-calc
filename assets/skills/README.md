# 공식 스킬 아이콘 넣는 곳

스킬 선택창은 이 폴더의 이미지를 스킬 ID로 찾아 표시합니다. 게임의 공식 아이콘은 게임사 저작물이라 저장소에 포함하지 않았습니다.
사용 권한이 있는 아이콘 파일을 직접 넣어 주세요(게임사 팬 콘텐츠 정책·이용약관 확인).

1. 파일 이름: `skill_<스킬ID>.webp` 또는 `skill_<스킬ID>.png`
   - 전투스킬 ID 예: `skill_10008.webp` (칼날 일격), 보주(비법) ID 예: `skill_10500.webp`
   - ID는 선택창의 스킬 순서와 `js/gamedata.js`(SKILLS) · `js/gamedata2.js`(CHARMS)의 `id` 값입니다.
2. `icons.json`의 `ext`를 넣은 확장자로 바꿉니다.

```json
{ "ext": "webp" }
```

파일이 없는 스킬은 속성 색 타일로 표시됩니다. 권장 크기 96×96 이상 정사각형.
